gapless.mp3 is a generated 1-second, 440 Hz sine tone, not a game asset. The source is 44,100 mono signed-16 samples at 44.1 kHz: round(10000 * sin(2 * pi * 440 * i / 44100)), for i=0..44099. Encoded with FFmpeg 8.0.1 / libmp3lame using `-c:a libmp3lame -q:a 4` with the default Xing/LAME metadata. This synthetic test fixture may be freely reused. Decoding must trim encoder delay and end padding to exactly 44,100 samples, including after rewind. The tested production decoder uses the minimal FFmpeg 9.0.2 libraries, not the encoding executable.

The compressed-content test compares the middle 0.1–0.9 seconds against the analytic sine after the default mono-to-stereo -3 dB rematrix. Both channels must match sample-for-sample, and relative RMS error must stay below 5%. Boundary transients are excluded from this content metric; full sample counts still check trimming at both ends.
